title: Your verification code
---
Some changes, such as rescheduling a delivery, need a verification code. The code is the last four digits of the recipient's phone number as the sender registered it.

We never ask for the full phone number, a password or card details. If the code is not accepted, check that you are using the recipient's number and not the sender's.

If the recipient's phone number changed, the sender has to update it, or you can open a ticket and our team will help you.
